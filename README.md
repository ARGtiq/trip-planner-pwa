# Trip Planner PWA

Простой и быстрый планировщик путешествий.

## Фичи

- Создание поездки за 10 секунд (куда + даты)
- Дни автоматически разбиваются
- Блоки Утро / День / Вечер
- Опциональный таймлайн
- Всё хранится локально (работает оффлайн)
- Устанавливается как PWA

## Запуск

Просто открой `index.html` или залей на любой хостинг (GitHub Pages, Vercel, Netlify).

Для PWA лучше открывать через HTTPS.
